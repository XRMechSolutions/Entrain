# Binaural Beats: Practical Parameters for Generation

Parameters below are **well-documented**; their *efficacy* is mixed (see
`effects-evidence.md`). Use them for sensible app defaults, not as evidence of effect.

## Carrier (base) frequency

| Guidance | Value |
|----------|-------|
| Hard limit for the illusion | Below ~1000 Hz |
| Strongest cortical response | ~250–500 Hz |
| Undetectable above | ~3000 Hz |
| Common values in studies | 240, 250, 400, 440, 480, 500 Hz |

## Beat frequency (inter-ear difference) by target band

| Band | Beat (Hz) | Commonly targeted for |
|------|-----------|-----------------------|
| Delta | 1–4 | Sleep, deep relaxation, pre-procedure anxiety |
| Theta | 4–8 | Meditation, relaxation, memory (often 5–7 Hz) |
| Alpha | 8–13 | Relaxation, creativity (~10 Hz) |
| Beta | 13–30 | Focus/attention (~15 Hz used for working memory) |
| Gamma | ~40 | Attention, "binding" |

Keep the beat ≤ ~30–35 Hz, or the two tones are heard separately rather than as a
beat. The band → use mapping reflects what studies *target*, framed as "commonly
targeted for," not "induces."

## Session & delivery

| Parameter | Guidance |
|-----------|----------|
| Duration | 15–30 min typical; longer exposure tends to be stronger; onboarding default 5–10 min |
| Headphones | **Required** — channel separation is definitional; no separation, no beat |
| Volume | Moderate, comfortable; protect hearing |
